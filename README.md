# Lidless

Keeps your Mac running with the lid closed while the apps you pick are open, and turns the screen off until you open it again.

[Download](https://updates.tired.dev/lidless). Apple silicon, macOS 15 or later.

## This repository

This repository holds Lidless's signed downloads and update feed. Each release's DMG and ZIP are attached to its GitHub release. `site/` is the download page and the Sparkle feed served at `updates.tired.dev/lidless`, deployed by `.github/workflows/deploy.yml`. Lidless's `scripts/release.py` publishes here.
