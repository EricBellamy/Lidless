Set up in a minute

Install

Open the disk image, drag Lidless to Applications and open it from there. macOS asks once whether to open an app downloaded from the internet; choose Open.

Add your apps

Click the eye in the menu bar, open Settings, and add the apps that should keep the Mac awake, such as a terminal or a render queue.

Close the lid

While one of them is open, the Mac stays awake with the lid closed. The screen goes dark, sound mutes and the display drops to its lowest refresh rate.

Lets the Mac sleep when it should

Lidless lets go when the last listed app quits, the battery runs low or the Mac gets too hot. It can also work only when plugged in.

Locks for anyone else

Opening the lid locks the screen before the desktop shows. So does a keyboard, mouse or display plugged into the closed Mac, unless you allow it.

Updates by itself

Lidless checks once a day and installs signed updates only when no listed app is open, so an update never restarts it while it keeps a closed Mac awake.

No administrator rights

Lidless is signed with a Developer ID and notarized by Apple. It starts at login as a background item, which you can turn off in Login Items.
